# Graphical abstract source

Run `python graphical_abstract/generate_graphical_abstract.py` after local reduced-data evaluation. Requires matplotlib and numpy. The script reads `fractions/evaluation/metrics.json` and generates PNG/SVG artwork and plotted values locally. The overview PNG is included for display in the repository README. Other generated image files are not tracked.

The schematic represents the study design; vector shades are illustrative. Narrative labels summarize the reported study and are not automatically inferred from newly trained results. Check them against the new evaluation before using regenerated artwork to report another run.
